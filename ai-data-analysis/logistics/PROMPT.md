# Antigravity IDE 开发任务

在当前 ops-center 的 AI 数据分析系统实现「领星物流履约与对账」。在现有功能分支直接编辑、运行和修复代码，交由 Codex 检查差异和创建 PR。验收合同见同目录《工作流.md》。先读 ai-data-analysis/README.md、shared/server.mjs、shared/lingxing.mjs、shared/connections.mjs 和现有首页导航及回归测试。

交付一个从首页可打开的中文工作台、通过共享网关提供的读写接口、持久化存储、可在现有服务环境运行的自动月结任务以及可重复执行的自动化测试。复用现有连接配置、权限和签名客户端。领星官方发货单详情及货件列表文档链接见工作流，按接口校验响应结构和分页。缺少凭据时以脱敏合成数据做契约测试，界面明确区分真实同步与演示。禁止读取或输出生产密钥、修改生产业务数据、部署或自行提交 Git。

用独立测试库从同步、改价、核费走到月结和评级，覆盖界面正常入口和 API。记录运行命令、通过数、失败数、数据规模、耗时、环境及未经真实租户验证的字段。检查 diff 仅含本功能。完工后在 IDE 会话报告改动和测试证据。
