# 多 MCP 使用说明

点击页面顶部 **MCP 连接组** 管理西柚和卖家精灵连接。组内从上到下使用。

- 地址与密钥写入 `proxy/connections.private.json`，由 Windows 当前账户 DPAPI 加密；页面列表不会返回密钥或完整地址。
- 只有明确的限流或余额不足才切换备用连接。参数错误、普通服务错误、超时不会自动重发。
- 补充步骤可引用 `{{site}}`、`{{asin}}`、`{{keyword}}`。不同平台的类目 ID 和资源 ID 不会混用。
- 卖家精灵返回 `secret_expired` 时，请在连接编辑界面更新密钥。

在项目目录运行 `start-local.ps1` 启动本地服务。
