# 物流商评级中心 v0.2.7-beta.18

日期：2026-10-22。状态：本地试用版，不作为正式财务或多人协同生产系统。本文件描述当前实现；历史版本说明见CHANGELOG.md及旧发布包。

## 报价与比较

- 仅比较本机日期所在自然周（周一至周日）且不晚于今天的报价。旧周不补位；报价按日期滚动保留30天，边界当天保留，仓库模板长期保留。页面聚焦、每分钟检查及读取时执行，无关闭浏览器后的后台任务。
- 按公司ID＋国家/渠道/仓库/币种/计费单位/条件更新：新日期替旧，同日再导入允许修订，旧日期不得覆盖新日期，未涉及范围保留。完全重复幂等；同批同范围同日矛盾价格、天数或时效口径保留冲突，不任取一条评级。
- 同国家、渠道、仓库、币种、单位、条件才同组。价格分=组内最低价/本家价×100；时效分=组内最短上限/本家上限×100；两项各50%，一位小数后S≥95/A≥90/B≥80/C≥70/D<70。至少两家公司无冲突报价才评级。
- 时效按每渠道每行原文提取；明确的行级公共参考时效可用于对应行。多渠道表优先使用合并标题范围确认归属，无可靠归属则留空，不向下填充、不统一人工指定或折算工作日。时效比较还要求至少两家公司且口径一致；缺失或口径未确认时只比较价格，无时效/综合等级。
- 地区→国家联动，支持服务商/渠道/仓库全局筛选。国家→仓库折叠；表头⌄提供列多选和排序、全选/全不选/清除此列设置，缺失值始终排最后。先按原组评分再筛选显示。导出仅应用顶部全局筛选，不包含列内局部筛选或排序。
- 比价不再截断200行；大数据量真实浏览器性能仍有限制，本轮已用10000条/500公司做浏览器容量验证；不代表所有设备或所有记录长度均达到相同表现。

## CSV及XLSX

| 对象 | 限制 |
|---|---|
| 单次CSV | 2 MiB、2000行；UTF-8或GB18030 |
| XLSX原文件 / ZIP展开 | 10 MiB / 32 MiB |
| XLSX表 / 非空单元格 | 100 / 150000 |
| 整本一键清洗 | 遍历可识别页的所有区块/档位，最多10000条，超限拒绝而非截断 |
| 原表预览 | 前80有效行、前24有效列 |
| 标准预览、账单、评级、仓库列表 | 最多200行；对应导出包含筛选内全部记录 |
| 每模块业务记录 / 公司 / 仓库模板 | 10000 / 500 / 5000 |
| 仓库纠错历史 | 1000条 |

复杂矩阵支持明确KG/CBM表头及A/B目的仓列；不承诺所有布局都能解析，逐表报告跳过与错误。旧版XLS、PDF不支持；不执行公式、宏、外部链接，公式仅显示文件缓存值。整本使用人工核对的生效日期和默认币种，不从缺年份文件名补造日期。修改公司/日期/币种后须重新清洗。复杂原表只在当前会话核对，草稿不代表已入库。

公司从全局档案、表内字段、文件名前缀识别，可人工选择；同名/别名全局共用。多公司冲突不自动猜选。税费默认不含税，明确含税/包税原文优先。缺值不生成价格或虚拟天数。

海外仓（谷仓、4PX等已识别名称）自动忽略并汇总，不入库、不生成模板、不参与比较。明确AMZ多仓逐仓拆分，包括IUTE/IUSF等四字母编号；缩写和模糊范围隔离。只做格式校验，不验证仓库实际存在。国家明确的工作表不会被AZ/TX等州字段覆盖；表内明确国家仍可形成多国家报价。

仓库按国家＋标准编号归并大小写、NFKC全半角、空格、零宽及格式分隔符；不会按编辑距离合并不同编号。人工纠错同步关联报价并留修改记录，不建立未来文件的永久别名规则。仅保存解析结果及文件名/表名/坐标等来源，不将原始上传文件保存到业务库。

## 月度账单与运营评级

账单CSV按账单日期归月，按公司与币种汇总及导出明细。支持CNY/USD/EUR/GBP/JPY/CAD/AUD/HKD；金额允许负调整，最多两位小数，单行绝对值不超过十亿元，按整数分计算，不换汇。已付留空视作0，金额缺失或非法日期不入账。完全相同行跳过；同账单修改金额后重导会形成另一行，需人工核实，不自动冲销、不做银行流水或双方逐票核销。

合作完成后由负责运营评价，按完成日期所在月份汇总。费用兑现30%、时效兑现40%、配合服务30%，按票等权；未评价不计零分，同公司同运单不重复计分。评分0–10、每0.5一步，月度分保留一位后S≥90/A≥80/B≥70/C≥60/D<60。不自动暂停合作。只选已导入公司，不恢复已移除轨迹模块。运营、单号及依据长度分别为50/100/2000字符；日期2000–2100年，完成日期不得晚于本机今天。

## 存储与安全

同源localStorage存储，无服务端数据库、登录权限、不可篡改审计或跨电脑同步。继续使用 http://127.0.0.1:8767；更换主机或端口会形成独立存储。支持Web Locks的浏览器对报价、账单、评级保存、公司编辑与全量备份使用同源共享写入锁，取得锁后等待存储事件同步，再检查快照；报价保留待保存预览并阻止旧预览覆盖；合作评级编辑中有外部更新时须刷新核对。Web Locks只协调遵循本协议的新版本页面，不约束旧版本页面、外部脚本或开发工具；不支持Web Locks时退回快照检查，须单标签写入。公司与业务记录仍不构成跨键原子事务。升级迁移和人工恢复应关闭其他写入页面，避免混用新旧版本。

损坏存储拒绝覆盖，配额失败不报告成功。HTML转义用户文本，导出CSV保护公式型文本。左下角全局档案可导出本应用四个键的JSON备份，不读取同源其他键；无一键恢复界面。Demo为合成数据，与真实业务记录以demo标记区分。

beta.17使用独立8769端口、本轮beta.18使用独立8770端口合成数据，未改写8767业务记录；既有错误国家记录不会自动重写，应备份后按源文件重新核对/纠错。131项自动化通过及浏览器证据见TEST-REPORT.md；这不是正式生产或独立安全验收。

## beta.18 CSV往返与恢复边界

新版报价导出包含等级列、时效口径/确认状态/原文/备注及导出格式标记，可在原CSV限制内重新导入；派生等级会重新计算，不信任导入等级。兼容旧版15列比价报表，但缺少时效口径时仅比较价格。公式保护转义可逆，空值保持为空。CSV仍限2 MiB/2000行，超出的报表须分批；它不是完整业务库备份，不包含已折叠的冲突全部原始行、所有历史和全部来源坐标。完整无损恢复使用四键JSON全量备份，本版仍无正式恢复界面。

已验证0.2.0、0.2.6及0.2.7历史有效样本升级与重复迁移；回退只验证恢复升级前备份后由旧版读取，不保证旧版直接读取新版新增数据无损。
