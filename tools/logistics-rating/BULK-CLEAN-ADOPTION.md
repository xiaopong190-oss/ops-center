# 一键采用清洗后报价（beta.89）

用户明确要求在旧、新 UI 增加批量采用，替代逐条点击。指定价格规则仍待用户补充；界面不默认选择规则。

旧规则：逐条 ImportResolution.resolve(confirm) 采用当前区域报价，并把同条件同日期其他价格记为 alternative 忽略；原始证据与决定留档。

新增：独立 extensions/bulk-clean-adoption.js 纯函数按明确规则生成全量预览，调用原单条 resolve、区域合并与完整性校验；独立 UI 扩展在异常面板前提供“规则→预览→一次采用”。不改变分页、默认导入、比较、保留期、原校验或原有单条按钮。受保护核心源文件及锁清单均不修改。

按服务商、国家、原始渠道、区域、计费条件、币种及单位分别处理。最低/最高价规则保留日期分组；最新日期规则必须明确同日最低或最高。已有明确 confirm/edit/ignore 决定的组跳过。非区域价格冲突、无效数据、未知公司档案保持待核对。

原文、逐条 decision 与批量规则、操作编号均保留。预览后数据、目录、日期或规则变化会阻止应用，必须重新预览。主写入仍经 ComparisonStore.commit 与 Domain.withWriteLock，不调用外部 API，不自动上线。

回滚：移除 quotes.html 中两个扩展脚本入口即可恢复逐条 UI；既有原始证据和已明确执行的批量决定仍保留，不自动撤回人工决定。

测试：新增等价性、分组隔离、人工决定保留、无效项、幂等和 2,208 条模拟；运行完整 node --test tests/*.test.cjs，包括规则锁检查。价格规则未替用户选定；每次由操作者选择并预览。用户后续明确要求在老 UI 更新版本，通过独立 PR 发布。
