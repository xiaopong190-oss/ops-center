# 货物类型多选筛选

用户确认在顶部增加可多选的货物类型：普货、带电、带磁、液体、粉末、其他特殊货物、未注明／待确认。多选满足任一项，未选表示全部。依据当前行的已确认货物口径、货物类型、渠道和计费条件分类，保留原文证据；不依据整个文件名或其他行推测支持。出现否定或相互矛盾说明时不作支持判断。

旧行为：运输筛选后直接进入现有国家／仓库筛选和评分。新行为：独立纯函数在运输筛选结果后投影货物类型，再交给原有流程；原行对象不改写。评分、价格分组、去重、入库和持久化保持原样，不声称补齐原比较引擎中缺少的货物条件。报价未注明类型就归待确认，未注明不等同普货。

quotes.js 仅新增一个显式投影调用，用户本次确认多选功能为该界面集成授权；锁测试按精确调用还原旧语句核对原始哈希，未刷新默认哈希。撤回删除该调用、脚本加载和布局挂载即可。原分组与高分列表共用该投影，导出使用相同筛选；全局重置清除货物勾选。
