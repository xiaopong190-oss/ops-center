# 确认入库后云端备份

真实业务空间的报价确认导入、账单保存和合作评级保存后，自动备份本地公司、报价、账单、评级四键。Demo不上传。当前实现为当前登录账号独立备份，不是团队共享库；不会自动下载覆盖本地，也不会把不同浏览器的独立数据自动合并。

界面分别显示本地已保存、正在上传、云端已保存。只有收到后端有效保存凭据（版本、时间、行数）才记录成功。未登录、断网、校验失败、并发冲突时保留本地数据和待上传标记，提供重试；重新打开待上传页面会重试。

大于700KB的请求分片，每片512KiB，最高16MiB。服务器校验完整分片SHA-256、结构和公司引用后，以版本检查更新当前备份指针。未完成或失败上传不替换旧备份；重复操作号幂等。每天UTC 09:00运行清理：未完成上传保留24小时，历史备份保留30天；最新成功备份无论多旧都保留，当前账单/评级/公司档案不单独删除。早期缺少时间信息的备份保守保留，避免猜测误删。清理只处理物流云端备份键，不触碰运营中心其他业务。仍需监控D1容量，不承诺无限存储或自动跨设备恢复。

云端接口需要现有运营中心登录，按账号隔离，禁用编辑账号不能上传。保存凭据留在本地；不写API密钥，不更改DeepSeek配置。
