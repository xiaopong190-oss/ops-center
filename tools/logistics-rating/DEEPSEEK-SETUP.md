# 后台供应商辅助识别

DeepSeek仅在常规供应商识别为空或冲突时后台调用；正常识别不调用。不再识别表类型、字段、金额、时效、仓库或库存数量，不再显示独立AI面板。发送范围严格限定文件名和现有公司名称/别名/id，不发送工作表内容；每用户每日20次上限仍生效。只采用高置信度结果，已有人工选择不覆盖；失败或低置信度保留手动核对路径。模型不直接新增或更名全局档案。

密钥仍在Cloudflare ops-center-cloud的Secret DEEPSEEK_API_KEY，默认模型deepseek-flash。后台调用需运营中心已有登录；本地源不会共享线上登录。不把密钥写入聊天、GitHub或浏览器存储。

手动核对服务商名称是折叠入口，气泡提示通常不要手动改动。“用于当前文件”仅变更当前解析身份；“新增到公司档案”明确创建/复用名称，保留已有历史公司，报价仍需校验入库。全局改名沿用原全局档案编辑功能，不把本次文件名修正强行传播到历史记录。

用户已确认匹配对象为已有供应商/物流商档案；不涉及商品库存或仓库编号。
