# 物流商报价与评级工具

当前版本：0.2.7-beta.18，试运行（local-pilot）。

## 本地试用

在本目录运行 `python -m http.server 8767 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8767/index.html`。

首次体验整套合成演示数据，可访问 `http://127.0.0.1:8767/index.html?demo=all`，或在页面右上角“演示数据”中选择“载入整套Demo”。包含报价、账单和合作评级；记录有演示标记。请在独立浏览器配置或测试环境体验。日常打开普通 index.html，避免反复初始化演示。

## 演示保留政策

根据用户要求，试用期间和后续版本更新保留演示数据功能与合成示例。只有用户在版本更新要求中明确提出“取消演示”后，才移除演示内容。升级不得自行清除本机已有演示记录，也不得将真实业务记录替换为演示记录。

应用数据保存在当前浏览器、当前网站来源的 localStorage。GitHub 上传的是程序及合成演示生成器，不包含本机浏览器业务库。切换域名、端口或浏览器不会自动迁移数据；迁移前使用全量备份。
