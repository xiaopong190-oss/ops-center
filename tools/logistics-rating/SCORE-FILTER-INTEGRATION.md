# Global channel score filter — independent extension

Pure function: extensions/score-filter.js → scoreView(fullRankedRows, options). No score calculation, import, storage, business identity or writes. Default descending channelScore; equal scores retain original order; missing scores last. Optional inclusive min/max0–10 (fractional allowed), ascending/original order. Filtering and global sorting precede200-row pagination; all contains the full matching sequence for export. Current country/provider/warehouse scope must be applied by caller before passing already-ranked rows. Do not filter peers before scoring: a low-score offer may remain part of another offer's legitimate reference set.

## Required default rule change for review

An extension alone cannot globally reorder those existing groups without replacing/patching a locked function or reimplementing scoring. This PR deliberately does neither.
