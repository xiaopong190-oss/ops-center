# 高分列表列筛选与排序

高分列表原先只有全局分数筛选，没有原仓库分组中的列控件。现新增独立界面扩展，为参考分、国家、仓库、物流商、渠道、条件、报价、时效提供多选筛选与升降序，并可重置单列或取消。

作用范围与原分组列控件一致：当前页。翻页／全局条件变化后重置列选择，导出仍遵循原全局筛选。分数及价格按数字排序，时效按区间最晚天数排序，缺失值始终最后。不改变业务存储、评分、导入、全局排序、去重或报价范围。未修改默认锁定模块。撤回时移除 score-list-columns 加载及布局绑定，并恢复 score-filter 表头输出。

验证：真实渲染 DOM 中的多列组合筛选、数字排序、清空与恢复、取消、恶意名称转义和只读数据断言；完整物流回归。未上线。
