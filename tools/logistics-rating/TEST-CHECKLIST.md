# beta.18 必测清单与证据索引

本清单按用户提供的软件测试知识库并结合本地物流业务风险制定。实际执行结论以TEST-REPORT.md为准，不将测试方法名称或代码覆盖率当作通过证据。

| 必测项 | 执行方式及证据 | 边界 |
|---|---|---|
| 核心流程与冒烟 | 真实比价筛选/导出、账单月度、评级保存；131项回归 | 不代替用户业务验收 |
| 计算与数据一致性 | 三项评分、独立整数账本校验10000账单/10000评级 | 万行账单/评级为VM集成；报价为真实浏览器 |
| 导入导出 | CSV导出再导入，空值/时效口径/公式转义；真实万行导出 | CSV仍限2 MiB/2000行；报表不是全量备份 |
| 幂等与覆盖 | 重复文件/点击/同批重复；新替旧、同日修订、旧日期不覆盖 | 冲突原始全行用JSON保留 |
| 负面、边界与状态 | 30天/自然周/日期/容量/金额；非法旧数据不迁移；初始化等待预览 | 固定种子1000组属性测试、500组损坏输入 |
| 时间与时区 | 跨周/月/年、闰日；LA/上海/UTC的夏令时前后日历边界 | 使用模拟时区，不更改系统时钟 |
| 并发与旧快照 | 实际双标签同刻调用保存，三轮复测；锁异常释放 | 新版且支持Web Locks；不承诺外部脚本/旧版安全 |
| 故障与恢复 | 配额注入UI失败保留原库/预览、解除重试；Demo跨键失败回滚 | 真实磁盘耗尽/断电未模拟 |
| 备份恢复 | 真正下载四键JSON，恢复后逐键一致；实际10000条备份验证 | 人工/隔离工具恢复，产品无正式恢复UI |
| 升级与回退 | 0.2.0/0.2.6/0.2.7历史样本升级、重复迁移；旧版读取升级前备份 | 不保证新数据直接降级无损 |
| 容量与性能 | 10000报价、500家公司、1000仓；测量就绪/筛选/导出 | 本机单浏览器，非P95或所有硬件承诺 |
| 稳定性 | 固定beta.18十分钟、每30秒采样 | 短期稳定性，不是24–72小时耐久 |
| 安全与环境 | HTML/CSV公式、ZIP/XML边界、畸形输入及损坏存储保护 | 无独立渗透/依赖漏洞扫描/多浏览器验收 |

浏览器复跑：`node tests/browser/server.cjs`，打开 `http://127.0.0.1:8770/qa-capacity.html`。只使用专用8770合成数据，不在8767业务源运行测试。`qa-fault.html?side=A`与`side=B`用于双标签；`qa-export.html`截获生产代码导出Blob以核验内容，文件实际下载另由备份入口验证。

故障复现记录须包含前置数据、操作、预期、实际、原始日志；修复后保留用例并执行全量回归。致命/严重数据错误未修复前不能宣布交付。
