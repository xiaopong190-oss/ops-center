# beta35 多供应商报价扩容

报价50000、区域报价50000、可撤销记录50000、仓库模板20000；单次Excel清洗10000条与CSV2000条不变。GitHub读写、D1上传分片及前端字节检查统一32 MiB。GitHub文件采用紧凑JSON，避免缩进膨胀；仍受总字节上限约束，并不保证每种长文本记录都能达到条数上限。

报价和大草稿迁移到IndexedDB，原缓存成功持久化后才移除localStorage旧值，失败保留旧值；同步成功以前等待缓存flush。WebLock操作前刷新、操作后flush；跨页刷新按真实/演示原键触发，认证信息仍由原存储管理。缓存写入失败显示明确状态，不当作云端保存成功。

176项测试通过：5万条边界、8MiB缓存写入及重开、迁移失败保留原值、后续失败重试、跨页刷新、演示隔离、原有回归。真实原表6483条与原库4672条离线合并11155条通过校验，紧凑数据约5.9MB（不含所有来源附加字段）。未向线上写入测试数据。超过原16MiB上限的约18MB分片数据已在隔离SQLite中完成上传/提交/下载往返；32MiB真实满载GitHub上传和真实浏览器IndexedDB交互未实测，限额是保护阈值；未宣称无限容量。
