# beta.59 取消逐项确认，异常报价自动AI复核

移除未纳入行逐项填写理由、逐项勾选的门槛。规则清洗完成后即可继续校验入库，异常报价片段交给现有DeepSeek后端分批复核，界面只显示一条处理汇总。AI不可用、未登录、超时或低确定性不阻断已通过数据，也不会冒充复核成功。

仅允许模型引用原始价格单元格、目的字段、单位和渠道坐标。恢复连写仓号时必须完整保留原字符。国家、单位、价格均由本地规则再次验证。不得猜造源表错误、缺失价格或时效。已转入标准校验后，迟到AI结果不改变该批数据。

真实原文件验证：27786行参考资料不形成门槛，38行异常报价进入队列；1个图片页保持原图提示，当前文本AI未处理。DOM测试：原28127行未纳入记录对应必填理由0个、勾选0个，仅显示摘要。模拟AI接口4批覆盖38项；不是在线真实模型调用。

246项物流测试通过；新增后端白名单、伪造坐标/价格/仓号、缺少配置及重定向测试通过。真实AI在线效果尚未验证。版本beta.59/N0.01.18仅本地完成，前后端均需发布后线上生效。
