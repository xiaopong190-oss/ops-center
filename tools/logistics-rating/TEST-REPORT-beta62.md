# beta.62 GW不同渠道误报冲突

美国海运海卡包税专线B15为美森CLX海卡包税13.9元/kg，E15为盐田统配8.8元/kg。前者B2:D2与B14:D14列范围对应，后者E2:G2与E14:G14对应。通栏A13:S13商卡专线仅为分段标题，原来覆盖了各列渠道，造成错误冲突。

修复：只有上下合并列范围完全一致时继承原渠道，保留分段文字，不借用不匹配列范围。真实同条件不同价仍被拦截。GW另有芝加哥/纽约拆柜同邮编不同路线，现将明确拆柜条件保留到计费条件；仓号附五位邮编仍使用仓库列，州缩写CA不再误当加拿大，但完整国家名称仍生效。
