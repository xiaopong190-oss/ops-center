# beta.69 全局同等条件去重

服务商、国家/仓库或区域、币种、单位、起始重量/档位、渠道与原计费条件、承诺时效(最少/最多天数、计算口径、是否确认、明确承诺原文)、带电、带磁、敏感货、货物类型全部作为相等约束。它们没有高低权重，也不以某个字段相同代替其他字段核对。未注明不等于否或普货。

仓库与区域存储去重、最新记录识别、同批区域价格冲突、人工选择价格时忽略同组其他价格、保存覆盖检查共用条件。区域也按全部条件相同的新日期替旧，旧日期不能反盖新日期。同一来源坐标但服务条件不同也不能被来源修订路径删掉。原表明确承诺时效列保存原文，参考时效不擅自改成承诺。

用户本次授权改变全局去重条件；10天周期、永久仓库模板、Amazon范围、原有价格/时效评级分数权重不变。比价展示的原有评分方法保留，不能将这里的“权重相同”误解为改评分。未自动修改实际数据或撤回人工已忽略决定。

旧数据缺失的新维度保持未知，与新文件明确条件分开保留，不能为维持旧总数静默删除。旧小满恢复脚本原先依靠同源覆盖68条不完整旧条件记录，现在会保留这些不同条件，因此其固定270断言不再适用；独立真实文件新入库、来源覆盖与重复导入应另核验。此前被人工忽略的报价需要按原文件重新清洗/核对，不能宣称已自动恢复。
