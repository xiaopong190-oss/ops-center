# beta.79 同商方案与时效区间评分

原先自动评分排除同一物流商同渠道，时效只看最晚天数。现在允许相同国家/仓库/服务/币种/单位/档位及货物条件下，同商不同价格或时效方案互比。完全重复方案不自比、不制造分差。其他物流商仍沿用每渠道中位数，避免重复源行增加权重。

价格沿用3%容差、最多±1.5分。时效同口径且已确认时，分别计算最早/最晚相对中位参考的优势，取两端点百分比平均；保留5%容差和最多±1分。两个端点一好一差则显示取舍，不自动加减。价格与时效独立累计，刷新重复比较不累加。缺失时效不伪造、0.1信息扣分与人工运营记录不变。

真实长河原表DTM2同100KG+普线两条：4.80元35–50天，5.00元40–50天，均为开船至交仓/自然日。隔离运行正式页面评分入口：前者价格+0.5、时效+0.5、基准后6分；后者价格-0.5、时效-0.5、基准后4分。真实数据未写入或上传。

新增6项回归：同商双项加减、区间交叉、重复源行、起重和带电/带磁/敏感货隔离、阈值封顶、正式评分入口保留不同时效记录。导入、存储去重、价格/时效等级算法未改；本次完善渠道参考分。完整307项回归通过后发布。
