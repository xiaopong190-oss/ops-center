# v0.2.7-beta.18 扩展回归与可靠性报告

日期：2026-10-22。原beta.17基线111项，本轮新增20项，当前131项自动化通过，0失败、0跳过。命令：`node --test tests/*.test.cjs`。原始最终结果由发布构建保存至test-results.tap。

本轮根据用户提供的软件测试知识库，补测容量、稳定性、并发、故障、备份恢复、升级回退及数据往返。测试只使用独立8770源的合成数据和隔离VM，未向8767提交测试业务记录。历史beta.17报告见TEST-REPORT-beta17.md。

## 发现并修复

1. **报价导出不能重导**：原15列比价报表被11列模板校验拒绝。新增可识别的20列导出格式，保留时效口径/确认状态/原文/备注、空值，并可逆处理CSV公式保护和原始单引号。等级只作为报告，不信任导入等级；旧15列导出缺口径时仅比较价格。CSV仍限2 MiB/2000行，超出须分批；完整备份用JSON。
2. **非法旧数据先被改写**：可解析但金额/评分非法的旧账单、评级，在业务校验前已被迁移添加公司ID。现在先完整校验，再迁移；非法数据及公司档案保持原样。失败复现见evidence/resilience-before.tap。
3. **万行渲染过慢**：同样10000条报价/500公司，全壳首轮约16070.8ms；公司名称按原始目录快照建立缓存后，同一测试方式约3072.4ms。进一步避免在导入/仓库页构建隐藏的万行比较DOM。缓存遇到更名、外部快照或损坏数据不会沿用旧值。
4. **同时保存存在时间窗口**：快照检查不足以阻止两个标签同时通过检查并报告成功。给新版保存、公司编辑、全量备份、Demo操作和报价清理加入同源Web Locks协调；取得锁后让存储事件同步，再重新检查快照。三轮真实浏览器同刻底层保存均为一方成功、另一方拒绝并保留预览。
5. **异步初始化与早到预览竞态**：读取锁尚未完成时，预览可能使用错误快照或被后续初始化覆盖。文件/整本预览等待初始化完成；新增延迟读取回归。
6. **公司同步重建主壳iframe**：公司订阅更新会重新渲染整个主壳，销毁待保存的模块会话。现只更新名称映射，子模块自行同步。旧测试复现5次重建、预期1次；修复后浏览器iframe引用不变、2个预览行保留、公司名称更新，四键可精确还原。

## 真实浏览器容量与导出

合成数据：10000报价、500公司、1000仓、3国；附带500账单与500评级，四键约3299639字符。未把所有模块都装满来假设浏览器配额无限。

最终直接比价页就绪探针：10000行、200601个DOM节点，约1419.5ms；地区欧洲筛出3330行约282.3ms，恢复10000行约375.5ms；生成并解析导出Blob约109.4ms，10000条、20列、1752046字节，与当前筛选范围一致。此探针避免系统保存文件弹窗干扰；真实文件下载另由全量备份验证。性能是本机单次观测，不是P95或所有设备承诺。原始数据见evidence/export-performance-final.json。

## 真实双标签并发

两标签先各建立1条待保存预览，再约定同一时刻调用生产保存处理器，强制覆盖按钮禁用前后的底层防线。三轮开始时间各自一致，结果均为一方保存、另一方提示“其他页面已修改报价，请刷新后重新校验”；失败方保留表头＋1条预览，库始终10000条。见evidence/race-after.json及race-protected.png。

Web Locks仅协调遵循新版协议的页面；旧版本、开发工具、外部脚本和不支持锁的浏览器不在保证范围。localStorage仍不具备跨键原子事务；升级与恢复须单标签。

## 故障与恢复

实际报价UI注入QuotaExceededError：原库逐字不变、10000条仍在、待保存预览保留；恢复后重试保存1条修订，记录总数仍10000。随后将四键恢复到基线，逐字一致。Demo跨键中途失败的回滚由自动化验证。未通过填满真实磁盘或破坏用户数据来制造故障。

真实“导出全量备份”生成6297588字节JSON，只含4个应用键：500公司、10000报价、500账单、500评级。实际下载文件在隔离VM恢复并经业务校验，记录与关联逐键一致；恢复界面仍未作为正式产品功能实现。见evidence/migration-results.json；全量合成备份留在工作区QA目录，不随发布包附带。

## 固定最终代码稳定性

固定beta.18真实浏览器连续600秒、每30秒采样，共21个样本：全部为10000个显示行、10000条存储记录，错误文本为空，版本一致。采样堆内存约16.25–23.18 MB，首尾约16.94/20.24 MB；短期波动不能证明长期无内存泄漏。见evidence/soak-final.json及soak-final.png。之前跨修复过程的记录仅保留为evidence/soak-pre-final.json，不作为最终冻结代码验收。

独立核心循环持续600.35秒、300轮通过，保持1000条报价；每轮验证修订合并、重复幂等、数据校验、评分和空时效矩阵解析。循环耗时P95约35.39ms。运行前后8个生产源文件SHA-256一致，见evidence/endurance-final.json。23处首方脚本引用及最终采样由确定性脚本独立核对，见evidence/release-audit.json。

已尝试用户授权的Cursor编辑器/Agent命令行入口，但没有成功提交Agent任务。机械核对任务已写入工作区QA目录的CURSOR-TASK.md；本报告所有已完成结果均由Codex与本地脚本执行，不归功于未执行的Cursor任务。
