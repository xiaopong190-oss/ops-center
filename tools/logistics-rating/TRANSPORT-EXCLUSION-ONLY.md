# 运输方式仅不限与排除

用户于2026-10-25明确要求“运输方式只设不限与排除，不要那个纳入”。

旧按钮三态neutral→include→exclude；新按钮只在neutral与exclude之间切换。独立纯函数extensions/transport-exclusion.js决定下一状态，n001.js只有按钮点击接入点调用此函数。多种方式可分别排除，重置恢复全部不限。未知运输方式仍按原综合方案规则处理。

不修改运输识别、status/matches、分组、导入、存储、评分公式或删除实现。旧include内部能力保留兼容既有测试/调用方，但界面不再创建该状态。HTML加载新扩展后再加载n001，按钮脚本使用exclude-1缓存参数。

原n001.js锁定哈希不更新。锁测试仅对逐字匹配一次的已批准按钮接入片段还原后校验原始哈希，其他代码改动仍会失败。回滚恢复按钮接入和HTML脚本列表即可，不需数据迁移。

验证涵盖反复切换、遗留/非法状态、多方式排除、未知方式、重置、存储不变、实际UI点击回调、依赖加载顺序，另跑完整物流回归。沿用用户此前直接更新界面并上线内部测试的授权。
