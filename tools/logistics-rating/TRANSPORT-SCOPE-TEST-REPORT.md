# 运输方式与查看范围测试报告

日期：2026-10-26（America/Los_Angeles）。仅增加测试及 CI，不改功能、默认规则、业务数据或线上版本。

## 结果

- 物流模块 Node 回归：353 项通过，0 失败。
- 新增专项：4 项逻辑测试、1 项真实 n001.html 的 JSDOM 交互测试通过。
- 整站：15 组回归套件全部通过，隔离数据运行。
- 现有合作评级 DOM、市场使用边界测试、报价导入 DOM 测试通过。
- 只读获取线上 n001.js，与本地受测脚本规范化换行后完全一致。

## 覆盖

1. 海运、空运、卡航、铁路：16 种排除组合与 4 种查看范围逐一断言精确结果；包括默认、单项、多项及全部排除。
2. 查看范围：范围内＋综合方案、仅运输待确认、仅范围外、全部运输范围；范围内与范围外的并集完整、不重复。
3. 原始 HTML 控件点击、切换下拉选项、重置顶部筛选、评分确认状态失效、分页重置和零结果。
4. 未选仓库禁止比较；选择国家和仓库后允许比较；再次修改运输方式后清除比较确认状态。
5. 海铁归海运、空派归空运、中欧班列归铁路；卡派和快递派不直接归卡航；矛盾的辅助证据保持待确认；明确渠道优先于表名。
6. 空名称、缺失名称、长字符串、空字符和 HTML 注入文本；注入字符串不能在运输统计区域生成脚本或图片。
7. 旧 include 状态、非法状态连续切换 10000 次，均只产生 neutral / exclude。
8. 10 万条报价全部排除时，8 万条已识别报价归范围外，2 万条待确认保留在默认范围内；无丢失或重复。此为内存筛选压力测试，不代表渲染十万行的浏览器性能。
9. 测试前后原始报价数组及隔离存储哨兵一致，筛选行为不写业务存储。

## 当前规则须知

- 四种运输方式全部排除后，“范围内＋综合方案”仍保留运输待确认的报价，不应断言结果一定为空。
- “全部运输范围”会展示已排除方式；查看排除结果请选择“仅范围外”。
- 运输统计是全局统计，未应用后续服务商等筛选，故不要求等于最终列表条数。

本轮覆盖范围内未发现功能缺陷。自动交互运行于 JSDOM，并非人工桌面／手机浏览器视觉验收；未操作用户实际业务数据，未测试生产环境删除或入库操作。
