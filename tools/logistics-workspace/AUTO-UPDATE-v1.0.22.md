# 航序 v1.0.22 自动更新

旧版没有联网更新代码，需先把本版复制覆盖补丁安装到原航序文件夹一次。此后保留原“启动航序.cmd”入口；在本机服务已关闭的情况下启动时，会自动检查官方新版本、下载变化的应用文件并校验后安装。正在运行的服务不强制停止，下一次关闭服务后的启动再更新，例如重启 Windows 后。普通刷新浏览器不等于重启本机服务。

更新失败继续使用原版；替换过程或新版首次启动失败时恢复原应用文件。原文件备份和恢复记录仅位于应用目录内。不清空浏览器数据库、不换地址、不换命名空间、不迁移报价、不自动发布业务快照、不读取账号凭证；原清洗和默认规则未修改。

每次 Pages 发布会从应用白名单生成完整清单，以及按 SHA-256 命名的不可混用资源。仅下载变化文件；拒绝越界路径、链接路径、重复路径、过大文件、降级和摘要不符。新版启动通过现有健康检查后才确认更新；断电或进程中断留下的未确认更新在下次启动恢复。

专项覆盖：联网正常与离线、运行中延后、下载期间服务启动、坏摘要/混合版本、写盘失败、启动未确认恢复、恢复备份损坏、并发锁、同版本修复、完整生成清单，以及实际本机HTTP服务启动。测试仅使用临时虚拟安装目录。

自动更新解决版本长期停留在旧版的问题。它不会把旧固定上传批次变成当前数据：v1.0.21 的双范围预览与回执仍保留，有未发布变化时仍需核对并发布当前数据。
