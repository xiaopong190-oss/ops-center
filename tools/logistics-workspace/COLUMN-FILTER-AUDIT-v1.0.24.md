# 报价表头筛选核查

用户确认：保留当前页筛选，明确作用范围；不改为全量筛选。

## 现有范围

- 高分列表：当前页已渲染的行，最多200条。
- 原仓库分组：当前仓库表格内、当前页已渲染的行。
- 选项从该表全部已渲染行收集，包括被其他列条件暂时隐藏的行，避免选项因组合筛选后为空而无法恢复。
- 同表多列按交集筛选；排序只重排行，不改变勾选条件。不同仓库表格状态独立。
- 当前表被翻页、全局筛选或重绘替换后，表头条件不保留。导出始终遵循全局条件，不应用当前页表头条件。

16238条总结果不等于当前页筛选范围。其他页的渠道不出现在当前页候选中是范围限制；本版通过明确提示解决歧义，不扩大查询范围。
