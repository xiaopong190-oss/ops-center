# 输入端详细查看与网络展示

对应版本：本地 V1.0.60；网络 V1.0.60.a。后续仅调整网络展示时按 .b、.c 递增，基础版本与本地功能版本保持对应。

- 本地 input.html 的查询视图以及本机 display.html：保留原有数量、数据状态、异常资料质量、诊断和管理说明。
- 网络独立 display.html：默认报价查询；简短加载/更新状态、必要筛选、报价结果、导出和直白操作名称。不显示清洗异常、诊断、修正映射、独立试算或原始故障详情。
- 本次仅改变可见 UI，不删除本地记录、异常证据或修改报价分类/评分/发布/鉴权逻辑。原已归档的异常不会在网络界面单独展示。
- 真实加载失败保留简短提示及重新加载入口；已有快照时提示当前报价可继续查看。分数范围错误及缺少仓库等操作校验仍可见。
- UI 标记 presentation=public 不是权限控制，现有登录、只读保护和共享快照命名空间保持原流程。

检查包括：公网/本地版本区分、本地查看仍有详细状态、网络原始错误不显示、断网状态可操作、必要校验可见、仓库与运输方式及分数筛选、清空和重置不改业务记录。原有整页下拉联动回归继续执行。
