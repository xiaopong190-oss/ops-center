# v1.0.14 — identify quote blocks before cleaning

The workbook pipeline first scans all valid rows and classifies quote/reference/uncertain with source evidence. Confirmed quotation blocks enter the existing parser; uncertain sheets retain original evidence and do not enter quote cleaning. Warehouse reference metadata remains available to confirmed quote sheets. AI samples uncertain sheets across the workbook, must cite original destination/unit/numeric-price cells, and cannot invent prices or infer an entire long/image sheet is empty from a sample. AI absence, timeouts, quotas and limited scan budgets leave uncertain status. AI judgment is limited to six uncertain sheets and a 25-second budget per run; remaining uncertainty is visible. Image-only tables are held, not OCR-extracted.

Results separate warehouse and regional quotations, scanned row counts, quote preflight reasons and AI review evidence. A confirmed quotation with zero extracted rows explicitly reports unsupported extraction. Raw preview begins at 200 rows and can expand. Local authenticated AI traffic uses a fixed-purpose same-origin relay; cloud validates bounded samples and model output references. No locked parser or existing quote/scoring/retention rule was modified.

Offline verification: 406 business tests, 32 regression suites and final 25 focused preflight/Worker/UI/cloud tests passed. Synthetic cases include eight physical XLSX sheets, 5,000-line preamble, multiline tax tiers, regional and numeric-postal destinations, reference/fee sections, formula errors, enquiries, empty/image-only sheets, mass statistics without prices, prompt injection, fabricated AI cell references, API failures, 20,000-row scan and 100 mixed sheets. The original screenshot workbook was not supplied; no claim of exact workbook completeness is made. Tests used mocked AI responses, not a live model accuracy benchmark. Existing production snapshot data was not replaced by fixtures.

Deployment requires the matching local package for the new local relay and preflight stage. Current published display snapshots and business records require no migration.
