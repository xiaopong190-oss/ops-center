# v1.0.19 — 云端走货后合作评价

展示端“合作评级”改用独立受控录入页：角色为运营且有编辑权限的登录账号（或有编辑权限的管理员）可登记已完成走货、暂存待评价、填写价格/时效/配合度及依据，并修改自己录入的评价。操作人取登录身份，不接受客户端伪造。只读账号继续查看，不获得写权限；没有改变现有账号配置。

评价写入D1独立内部键空间，不写报价快照。报价快照发布不会覆盖云端评价。原快照评价只读展示，以服务商ID与规范化运单号合并，防止重复展示或计分。重复原快照运单也在服务端拒绝。服务商仍需来自已发布且在既有三个月名称有效范围内的档案；历史云端评价编辑保留自身身份。

每条评价以服务商ID及运单摘要确定存储身份，更新比较旧revision和数据库原值；他人修改、陈旧页面、并发重复新增均拒绝覆盖。保存只有在数据库写入及读回确认后才显示成功；失败保留输入。无删除入口。超过三个月完成范围的评价不在页面展示，内部历史未自动物理删除。

沿用原规则：0–10分、0.5步长；价格30%、时效40%、配合度30%，按完成月份汇总公司及渠道，待评价不计零分。未来日期、反向日期、无效日期、未知渠道、过长依据、伪造服务商和操作人均拒绝。服务商与运单为固定身份，编辑时不修改这两项。

报价查询仍只读，展示端仍没有报价上传或清洗入口。本地旧合作录入不受影响，不修改受保护评级/清洗底层模块。云端评级和旧快照采用不同保存范围，经营概览中的原快照计数不作为新云端评价总数；合作页展示合并后的实际记录与覆盖情况。

验证采用虚拟数据及独立SQLite：真实DOM表单提交到实际云端验证和存储、自己的编辑、只读账号、他人记录、并发重复、版本冲突、原快照重复、日期/分数/文本异常、名称保留和权重汇总。线上不录入测试评价，不覆盖现有报价快照。

用户明确授权测试后上线。部署云端API后发布新展示页；回滚显示页不删除独立评价记录。最终测试及部署结果见交付说明。
